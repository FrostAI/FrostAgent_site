# 使用与管理记忆

长期记忆用于保存后续对话仍有用的信息，不是完整聊天记录。最近的聊天内容、群摘要和长期记忆用途不同；本页先介绍控制台里的查看与维护操作。

## 让 Bot 记住信息

真实对话可以触发自动记忆提取，也可以明确要求 Bot 记住某项信息。自动提取与反思依赖相应模型路由，可能在累计多轮对话后才执行，不保证每句话都会立刻保存。

要验证持久化记忆，请使用已经接入的真实聊天平台。「直接对话」是临时模拟会话，不写入长期记忆，也不能用来验证自动提取是否落盘。

## 查看和修正条目

1. 先在「实例管理」选择正确的 Bot，再打开「记忆管理」。
2. 检索相关条目，核对内容、归属与来源证据；查看群档案时同时确认群 ID。
3. 发现错误时，按页面提供的操作编辑或删除。来自图片或第三方转述的内容，不一定是当事人亲口说过的话。

私聊记忆和群聊记忆有各自的边界。同一个人出现在两个群中，不代表两群记忆共享；不要仅凭昵称判断条目归属。

删除前确认选中的条目。清理会话不会自动清空长期记忆，修改长期记忆也不会重写历史消息。

## 调整群成员称呼

在群档案中按成员 ID 编辑优先称呼和别名。清空优先称呼后恢复使用 QQ 昵称；称呼不会改变身份、管理员权限或记忆归属，也不会跨平台、跨群同步。

用户也可以在真实群聊中要求 Bot 记住自己的称呼。若称呼有误，先核对原始消息，再在群档案中修正。

## 备份与恢复

在「系统设置 → 备份与还原」下载 `memory.json`，或使用包含记忆、档案与归档的全量 ZIP。大批量修改或迁移前先保存备份。

记忆导入按 ID 合并，同 ID 跳过，现有群档案优先；不同 ID 仍可能表达重复内容，需要人工检查。当前数据存储在 SQL，旧 `agent` 命令不是当前数据库的备份工具。完整步骤见[数据库与备份](../operations/storage)。
