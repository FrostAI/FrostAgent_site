# 项目介绍

FrostAgent 是用 Go 编写的 AI 角色扮演与智能体调度框架。它把模型调用、人格、长期记忆、会话上下文和工具执行组织成一个集成的 AI Harness 后端，并通过适配器连接即时通信平台。

你可以用它搭建有固定人格的聊天机器人、参与群聊的助手，或能够调用外部工具与自动化任务的智能体。Web 控制台负责配置和排障，聊天平台负责收发消息。

## 主要能力

| 能力     | 可以做什么                                                                            |
| -------- | ------------------------------------------------------------------------------------- |
| 多实例   | 在一个服务中运行多个实例，隔离人格、设置、记忆、会话、MCP 与表情包等                  |
| 模型路由 | 为主对话、子 Agent、图片理解、反思、记忆提取、群聊压缩与 Embedding 选择模型，按群覆盖 |
| 平台适配 | 通过 OneBot v11 反向 WebSocket 接入上游，或使用 AstrBot 适配器插件（未来会支持更多适配器）                      |
| 人格     | 使用系统提示词和示例对话引导表达风格                                                |
| 记忆     | 自动提取和手动维护长期记忆，管理群档案、群摘要与反思归档                              |
| 群聊     | 支持通过艾特、名称/别名唤醒 Bot，同时支持主动回复水群              |
| 工具     | 导入 Skills 技能包，调用工具与 MCP 使用，连接外部沙箱执行命令                 |
| 安全     | 支持接入 Watchdog 模型对 Bot 行为进行审查，也向 Bot 暴露封禁工具防止滥用|
| 运维     | 检查发送的 context、可视化 compact 会话、日志，导出并还原实例存档                             |

## 如何运作
### 拓扑

```text
上游消息
   │ OneBot v11 或 AstrBot WebSocket
   ▼
FrostAgent 实例
  ├─ 消息路由、唤醒与安全入口
  ├─ 人格、会话、长期记忆与群摘要
  ├─ 模型路由器 → OpenAI 兼容模型服务
  └─ 工具循环 → MCP / 隔离沙箱 / ActionsCat
        │
        ▼
适配器发送回复并确认投递

Web 控制台 → 管理实例与全局设置
SQL 数据库 → 保存配置和持久化业务数据
```

### 技术栈

服务端使用 Go、ConnectRPC 与 Protobuf；控制台使用 Vite、原生 TypeScript 和 Tailwind CSS。控制台静态资源编译后嵌入 Go 程序，部署时无需另外运行前端服务器。主页使用 11ty，本文档站使用 VitePress 部署。

## 实例隔离与共享资源

人格、默认路由、群级路由、会话、记忆、表情包和 MCP 配置属于实例。模型供应商、供应商凭据和模型目录由所有实例共享，发布供应商修改会影响使用它的实例。

Skills 同样按实例保存。群档案和群记忆进一步按规范化平台与群 ID 隔离；QQ 的 OneBot 与 AstrBot aiocqhttp 接入共享 `qq` 平台，同号的其他平台群不会共用数据。

监听地址、数据库选择、沙箱接入、安全模式和全局访问锁属于控制面。同一用户的封禁跨实例生效，后续有计划支持单独配置。

## 使用前准备

- 一个可用的 OpenAI 兼容模型服务（暂不支持 Anthropic，需要自行中转）；涉及工具调用时，模型需要支持对应能力。
- 源码构建需要 Go、Node.js、pnpm 与 Buf；使用 Make 构建时还需 Make 与 Bash。
- 如果要接入真实聊天平台，配置上游消息平台适配器。
- MCP、沙箱、ActionsCat 与 Alcyone 都是按需启用的外部集成。
