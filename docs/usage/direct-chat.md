# 直接对话

「直接对话」是内置的 WebSocket 协议模拟器。无需连接真实上游，就能测试当前实例的模型与人格。

## 断电全丢

模拟连接带有 `mock=true`，会话使用连接级独立命名空间。断开时取消在途工作、清理临时会话并释放相应沙箱资源，服务重启也不会恢复。

模拟模式允许只读召回长期记忆，但不更新召回元数据；禁止记忆写入与反思，不会自动提取、群摘要落盘和贴图摘取，不改变真实用户的封禁与违规状态（但会保存 `mock` 平台命名的记录），跳过 Alcyone 计费。

模拟模式仍会调用模型服务；MCP 业务工具与隔离沙箱可能执行实际外部请求。它不能替代外部工具的权限控制或真实平台联调。ActionsCat 的执行和变更工具在模拟模式下被拦截。

连接失败时，检查实例状态和代理 WebSocket 支持；会话断开后的丢失属于预期行为。
