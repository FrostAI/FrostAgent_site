# 会话与 Prompt

此功能用于可视化地显示会话、群摘要和当前构造的模型上下文，配合模型日志核对实际请求。

## 查看会话

1. 选择实例，打开「会话与 Prompt」。
2. 刷新列表，按会话 ID 或名称搜索。
3. 选择私聊或群聊会话。
4. 检查历史消息、群摘要和组装后的 Prompt。

会话按平台与群/私聊区分，模拟连接不展示。群级模型配置入口与会话列表关联，可以在排障时核对该群实际使用的路由。

## Prompt 包含什么

发送给远端端点的 Prompt 可能包含系统提示词、示例对话、工具、已加载的 Skills 指令、长期记忆、群档案、滚动摘要、近期未压缩群消息、引用来源以及本轮用户输入。部分情况（如触发主动回复逻辑）会触发额外提示词。

`MAX_CONTEXT_MESSAGES` 代表单个会话保留的最近对话条数，超出后裁掉最旧消息，最小 4，代码默认 50。群聊回复时，临时附带的「尚未压缩成摘要的群消息」总长度为 `GROUP_RAW_CONTEXT_MAX_CHARS` ；这些都不是上游模型的 Token 上限。图片、工具 Schema 和其他注入部分也会消耗上下文。精确请求应以对应的 `LLM_REQUEST` 日志为准。

## 压缩与清理

手动压缩可以立即整理当前上下文，需要对应压缩模型可用。群摘要可以单独查看、删除并备份。

清理前区分以下操作：

| 操作               | 影响                                               |
| ------------------ | -------------------------------------------------- |
| 压缩               | 生成话题摘要        |
| 删除群摘要         | 移除摘要，不等于删除长期记忆                 |
| `/reset`           | 重置当前会话上下文和摘要 |
| 记忆管理中删除条目 | 修改长期记忆，不替代会话重置                       |

服务重启会丢失内存会话历史；SQL 中的长期记忆和群摘要仍可保留。实例存档不是完整运行中会话的快照。

群聊自动压缩把压缩规则与待整理消息分别作为指令和输入传给模型。群消息里出现的角色声明或压缩要求仍属于待整理内容，不会成为控制压缩过程的系统规则。

Prompt 和日志可能包含真实对话、工具输入与结果。与他人分享前注意脱敏。
