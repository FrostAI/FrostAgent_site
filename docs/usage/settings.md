# 设置与生效方式

「系统设置 → Bot 服务端设置」使用中文表单管理 SQL 配置。

## 保存后何时生效

| 配置类型                 | 行为                                                                           |
| ------------------------ | ------------------------------------------------------------------------------ |
| 页面标注支持热更新 | 保存后由控制面或运行时读取新值；例如群回复策略、Bot 用户列表、ActionsCat 开关  |
| 需要重建实例       | 保存后自动重新装配运行时，可能中断连接和任务；内存会话会尝试转交给新运行时 |
| 管理监听地址             | 地址改变后从新地址打开页面        |
| 额外 env 注入项          | 保存到数据库，重启整个 FrostAgent 进程后才生效                                 |

普通实例配置无需额外手动重启进程。

## Bot 用户列表

在「Bot 行为与回复策略」的 Bot 用户 ID 列表中逐项添加、删除已知 Bot。单个 ID 适用于所有平台，`platform:ID` 可限定平台。保存后统一应用，配合连续对话轮数和 `soft` / `hard` 策略防止循环，详见[群聊策略](./group-chat#限制-bot-互相循环)。

## 额外 env 注入

页面底部的额外 env 注入用于需要读取进程环境的外部组件，支持添加、修改和删除。

保存或删除后重启 FrostAgent。宿主环境已有的同名变量优先；移除注入项不会移除宿主环境变量。**全局设置 JSON 会明文携带 `extra_env` 的值**，导出文件可能含外部组件凭据，应按敏感备份保存，分享前逐项移除。

全部键名、范围和约束见[配置参考](../reference/configuration)。
