# 安全控制

「安全控制」管理全局安全模式、禁用用户与审计记录。主体使用规范化 `(平台, 用户ID)`，QQ 的 OneBot 与 AstrBot aiocqhttp 接入共享 `qq` 身份。

## 三种模式

全局 `SECURITY_CONTROL_MODE` 支持：

| 值               | 行为                                                                 |
| ---------------- | -------------------------------------------------------------------- |
| `off`            | 选中后不再审查内容和封禁用户，之前已经被封禁的用户照常不可用             |
| `simple`（默认） | 保留访问控制与受限管理工具，不进行全链路 L·M 语义分类                |
| `aggressive`     | 每次响应结果（包括工具调用结果等）全部注入审查模型，放行后再请求远端端点 |

开启 aggressive 前应当配置可用的反思模型路由，安全网关使用该路由。分类器响应错误，会阻断相应请求，不会放行。

## 封禁用户

手动封禁在全部实例生效，可由管理员在控制台解除，或使用[管理员指令](../usage/commands)。模型 / 工具输出和引用上下文不能直接把无关用户当作违规者惩罚。直接对话不影响真实平台用户。

## 管理面认证

普通构建的远程管理 API / RPC 统一要求控制令牌，覆盖设置、实例生命周期、数据库切换、备份、日志和业务管理服务。`MCP_CONTROL_TOKEN` 优先，未设置时兼容 `ADMIN_TOKEN`；`ALLOW_REMOTE_MCP_MANAGEMENT` 无法绕过统一鉴权。

1. 在本机「Bot 服务端设置 → 安全与权限」配置「管理控制令牌」并保存。
2. 远程浏览器打开「系统设置 → 前端设置」，填写相同令牌。
3. 网页将令牌存入当前 Origin 的 localStorage，并为管理请求附加 `Authorization: Bearer <令牌>`；换域名或清理浏览器存储后需重新填写。
4. 自建客户端也须携带该请求头。不要把令牌放入 URL、公开日志或截图。

可信回环访问默认免令牌；`MCP_ENFORCE_LOCAL_TOKEN=true` 时本机也要认证。反向代理保留公共 Host 或转发标识；若代理同时改成回环 Host 并清空转发标识，必须强制本机令牌，避免把远程请求误判为本机。

[容器构建](../guide/docker)通过数值回环管理监听和共享网络命名空间隔离入口，由整个公开域名上的 Cloudflare Access 负责外部认证。Tunnel 能连通不代表 Access 策略已生效。该构建信任的是实际回环 connector 连接，不是任意请求自报的 Cloudflare Header；显式开启的本机强制令牌仍须提供。
